## О проекте

OrderParser — веб-приложение, которое собирает заказы на грузоперевозки с разных розничных площадок в одном окне. Цель — дать перевозчику единую платформу вместо необходимости проверять каждый сайт вручную.

Проект разрабатывается в рамках дисциплины «Методы и средства проектирования информационных систем» (4 курс).

**Текущий этап (лабораторная работа №4):** проектирование интерфейса и внешнего вида рабочей версии. Три функции (список, форма, страница отказа) оформлены с помощью Bootstrap, данные сохраняются в базе PostgreSQL.

**Планируется:** парсинг заказов с розничных площадок (Scrapling), расширенная фильтрация и поиск.

## Запуск

Проект поднимается одной командой с помощью Docker Compose. Сборка на вашем компьютере не требуется — скачиваются готовые образы приложения и базы данных.

Репозиторий: `https://github.com/ixtis/OrderParser`  
Ветка: `lab4`  
Pull Request: `https://github.com/ixtis/OrderParser/pull/4`  
Образ: `ixtis/orderparser:0.0.4`  
Страница образа: `https://hub.docker.com/r/ixtis/orderparser`

### Команды для запуска

```bash
git clone -b lab4 https://github.com/ixtis/OrderParser
cd OrderParser
docker compose up -d
```

После запуска откройте в браузере:
**http://localhost:8080**

На странице отображается название продукта, описание, версия `0.0.4` и статус разработки. Данные хранятся в PostgreSQL и не пропадают после перезапуска контейнеров (том `dbdata`).

Для остановки контейнеров используйте `docker compose down` (без флага `-v`, чтобы сохранить данные).

### Сборка образа (для разработчика)

Если нужно собрать образ самостоятельно и запушить его в реестр под две архитектуры:
```bash
docker buildx build --platform linux/amd64,linux/arm64 -t ixtis/orderparser:0.0.4 --push .
```
